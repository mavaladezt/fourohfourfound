This is the first post.

The site is a skeleton for now: one column, no JavaScript shipped to the
browser, dates in `MM/DD/YYYY`. The logo is a placeholder.

To write the next one, drop a Markdown file in `src/content/posts/` with a
title and a date in the frontmatter. It shows up on the index automatically,
newest first, grouped by year.
